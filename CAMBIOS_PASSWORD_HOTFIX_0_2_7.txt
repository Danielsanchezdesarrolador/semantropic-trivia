SEMANTROPIC TRIVIA — ALPHA 0.2.7
PASSWORD RECOVERY HOTFIX

NUEVAS FUNCIONES

ADMINISTRADOR
- Generar contraseña temporal segura.
- Fijar manualmente una contraseña temporal.
- Forzar cambio de contraseña al próximo inicio de sesión.
- Cerrar todas las sesiones de una cuenta.
- La contraseña original nunca puede verse.
- La contraseña temporal solo se muestra una vez al administrador.

JUGADORES
- Botón Cambiar contraseña.
- Botón Cerrar todas las sesiones.
- Si entran con una contraseña temporal, el juego exige crear una nueva antes de jugar online.
- Al cambiar la contraseña se cierran automáticamente las demás sesiones.
- El progreso, rating, monedas, diamantes, logros y perfil no se borran.

SEGURIDAD
- Las contraseñas siguen almacenándose con scrypt + salt.
- Las contraseñas temporales tampoco se guardan como texto.
- Las sesiones antiguas se invalidan al restablecer/cambiar contraseña.

POSTGRESQL
- La tabla accounts migra automáticamente agregando force_password_change.
- No hay que crear otra base ni modificar DATABASE_URL.
