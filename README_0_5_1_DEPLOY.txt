SEMANTROPIC TRIVIA — ALPHA 0.5.1

ACTUALIZACIÓN
1. Descomprime este ZIP.
2. Reemplaza los archivos del repositorio actual por estos archivos.
3. Haz Commit en GitHub.
4. Render hará el deploy automático.
5. Cuando termine, usa Ctrl + F5 para limpiar la versión anterior del navegador.

NO CAMBIAR
- DATABASE_URL
- ADMIN_KEY
- Base PostgreSQL existente

PRUEBA RECOMENDADA
1. Entra a “Avatar”.
2. Cambia cabello o rostro y comprueba que la vista previa cambie al instante.
3. Prueba ropa, accesorios, aura, marco y fondo.
4. Abre Emotes/Sprays y Animaciones.
5. Cambia nombre/bio/título en Perfil público.
6. Ve a Multijugador y usa “Editar avatar y perfil”: debe regresar al mismo editor de Avatar.
